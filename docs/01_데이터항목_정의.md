# 1단계 데이터 항목 정의 (v1.0)

작성일: 2026-11-09 · 상태: **PM 승인 완료 (2026-11-09)**. 결정 내용은 8장 참고.

행사 하나를 "카드 한 장"이라고 생각하면, 이 문서는 그 카드에 어떤 칸을 만들지 정하는 문서다. 칸을 미리 정해 두어야 자동 수집기, 주최자 등록 폼, 검수 화면, 사용자 화면이 모두 같은 칸을 보고 일할 수 있다.

**읽는 법.**

- **필수**: 비어 있으면 게시하지 않는 칸. B안 자동 통과 기준인 "날짜·장소 명확"을 확인하는 데 쓴다.
- **선택**: 있으면 좋지만 없어도 게시할 수 있는 칸.
- **자동**: 사람이 입력하지 않고 시스템이 채우는 칸.
- ★ **추가 칸**: 처음 후보 목록에는 없었다가 PM 승인(2026-11-09)으로 추가된 칸.

전체 구성은 네 묶음이다. 사용자가 보는 **행사 정보**, 근거를 남기는 **출처**, 운영자가 쓰는 **검수·관리 정보**, 그리고 별도 명부인 **주최자 정보**다.

### 1-5. 저장하지 않는 것 (법적 기본선 1번)

- 원문 소개글, 홍보 문구, 사진. 사진은 주최자가 직접 올리고 사용에 동의한 경우만 저장한다.

**한 줄 설명 작성 규칙 (PM 승인).**

1. 원문 문장을 옮기지 않고, 저장된 사실 항목만 조합해 새로 쓴다.
2. 쓸 수 있는 정보: 규모, 참가 업체·브랜드 수, 주종, 회차, 주최 형태.
3. 쓰면 안 되는 표현: "최고의·특별한·놓치지 마세요" 같은 형용사·감탄, 음주 권장, 건강 효능, 경품·할인.
4. AI가 초안을 쓰고, 금지 표현이 걸리면 자동으로 검수로 보낸다.

## 2. 출처 (행사 하나에 여러 개)

같은 박람회가 공식 홈페이지, 코엑스 일정, 뉴스 세 곳에 실리면 행사 카드는 하나로 합치고 출처만 세 줄로 남긴다. 출처 하나가 삭제되거나 내용이 바뀌어도 다른 출처로 확인할 수 있다.

| 항목 | 구분 | 설명 | 예시 |
| --- | --- | --- | --- |
| 출처 링크 | 필수 | 원문 주소 | hankyung.com/article/… |
| 출처 유형 | 필수 | 공식 사이트 / 전시장 일정 / 공공데이터 / 언론 / 주최자 등록 / 사용자 제보 | 언론 |
| 매체·사이트명 | 선택 | | 한국경제 |
| 수집 일시 | 자동 | 언제 가져왔는지 기록한다 | 2026-06-10 14:22 |
| 마지막 확인 일시 ★ | 자동 | 행사 직전 재확인 때 갱신한다 | 2026-06-16 09:00 |

**자동 통과 판단과의 관계.** 출처 유형 중 하나라도 "공식 사이트 / 전시장 일정 / 공공데이터 / 언론" 또는 "인증 주최자 등록"이고 날짜·장소 필수 칸이 모두 채워져 있으면 자동 통과 후보가 된다.

## 3. 검수·관리 정보 (운영자만 보는 칸)

승인된 검수 기준(1영업일 처리, 3일 이내 긴급, 주말 긴급 확인)을 시스템이 지키려면 아래 칸이 필요하다.

| 항목 | 구분 | 설명 |
| --- | --- | --- |
| 등록 경로 | 자동 | 자동 수집 / 주최자 등록 / 사용자 제보 |
| 검수 상태 | 자동·운영자 | 검수 대기 / 자동 통과 / 승인 / 반려 / 보류 |
| 검수 필요 사유 ★ | 자동 | 날짜 모호 / 첫 등록 주최자 / 사용자 제보 / 홍보성 판단 필요 / 좌표 실패 / 중복 의심 (여러 개 가능) |
| 접수 일시 | 자동 | 처리 기한 계산의 출발점 |
| 처리 기한 ★ | 자동 | 접수 후 1영업일. 행사가 3일 이내면 당일로 바뀌고 "긴급" 표시가 붙는다 |
| 검수 일시 · 검수자 | 자동 | |
| 반려·보류 사유 | 운영자 | 짧은 메모 |
| 노출 후보 표시 | 운영자 | 결정 5번의 관리자 전용 기능. 일반 사용자 화면에는 영향 없음 |
| 주최자 | 연결 | 4번 주최자 명부와 연결한다 (주최자 등록일 때) |
| 제보자 연락처 | 선택 | 제보 확인용 이메일 하나만. 게시 후 일정 기간이 지나면 삭제한다 (법적 기본선 5번) |
| 행사 시리즈 ★ | 선택 | 매년 열리는 행사를 묶는 이름 (예: 서울국제주류&와인박람회). 알림 기능은 이후 단계 |

> **검수 대기 목록 정렬**: 처리 기한 → 첫 등록 주최자 → 사용자 제보 순으로 자동 정렬하면 승인된 처리 순서와 같아진다. 대기 건수가 50건을 넘으면 관리자 화면에 경고를 띄운다.

## 4. 주최자 정보 (별도 명부)

주최자는 행사마다 반복해서 적지 않고, 명부를 하나 만들어 행사와 연결한다. 전화번호부에 한 번 저장해 두고 이름만 골라 쓰는 방식이다.

| 항목 | 구분 | 설명 |
| --- | --- | --- |
| 주최자명 | 필수 | 상호 또는 단체명 |
| 주최자 유형 | 필수 | 바틀샵 / 바 / 양조장 / 수입사·유통사 / 전시 주최사 / 지자체·기관 / 기타 |
| 사업자등록번호 | 필수 (인증 시) | 첫 등록 때 확인한다. 운영자만 볼 수 있다 |
| 담당자 연락처 | 필수 (인증 시) | 이메일과 전화번호. 운영자만 볼 수 있다 |
| 인증 상태 | 운영자 | 미인증 / 인증 완료 / 정지. 인증 완료면 이후 등록은 자동 통과한다 |
| 공식 채널 링크 | 선택 | 홈페이지, 인스타그램 계정 주소 등 |

> 자동 수집으로 들어온 대형 행사의 주최자(예: 전시 주최사)는 이름만 기록하고 인증 절차는 거치지 않는다.

## 5. 값 목록과 판단 기준

### 5-1. 주종 (임시 확정)

와인 · 맥주(수제맥주 포함) · 위스키 · 전통주(막걸리·약주·청주·증류식 소주·과실주) · 사케 · 기타 증류주(진·럼·보드카·데킬라·브랜디) · 칵테일 · 종합(여러 주종)

필터 버튼이 너무 많아지지 않도록 8개로 묶었다. 샘플 수집 단계에서 빠진 주종이 보이면 조정한다.

### 5-2. 규모 판단 기준 (임시 확정)

방문객 수는 대부분 공개되지 않아 숫자 기준으로는 판단할 수 없다. 그래서 **장소와 주최 형태**로 판단한다.

| 규모 | 기준 | 예시 |
| --- | --- | --- |
| 대형 | 전시장·컨벤션 센터에서 열리는 박람회, 지자체 주최 축제 | 코엑스 박람회, 영동 와인축제 |
| 중형 | 기업·유통사가 주최하고 매장 밖 별도 공간에서 여는 행사, 또는 여러 브랜드가 참여하는 행사 | 백화점·카드사 와인 페스타, 브랜드 팝업 |
| 소형 | 매장 한 곳에서 여는 시음회·클래스·게스트 바텐딩 | 바틀샵 시음회 |

### 5-3. 지역

전국 17개 시·도 단위로 필터를 만들고, 상세 화면에는 시·군·구까지 보여준다.

## 6. 수집 대상 출처 목록

**수집 원칙**: 공식 API(정해진 규칙대로 데이터를 받아 가라고 열어 둔 창구)를 1순위로 쓴다. 웹페이지를 직접 읽어 오는 방식은 사이트별 수집 허용 규칙과 이용약관을 확인한 뒤에만 쓴다 (법적 기본선 4번). 이용 조건은 3단계 수집기 개발 전에 출처별로 다시 확인한다.

| 우선순위 | 출처 묶음 | 대상 | 방식 | 기대 규모 |
| --- | --- | --- | --- | --- |
| 1 | 공공데이터 | 한국관광공사 TourAPI(행사·축제 정보), 공공데이터포털 전국문화축제표준데이터 | 공식 API · 파일 | 대형 축제 |
| 1 | 뉴스 검색 | 네이버 검색 API(뉴스) | 공식 API (일일 호출 한도 있음) | 대형·중형 |
| 2 | 전시장 일정 | 코엑스, 킨텍스, 벡스코, aT센터, SETEC, 엑스코, 수원메쎄, 송도컨벤시아 등 | 일정 페이지 읽기 (약관 확인 필요) | 대형 박람회 |
| 2 | 박람회·축제 공식 사이트 | 서울국제주류&와인박람회, 부산국제주류박람회, 영동 대한민국와인축제, 군산 수제맥주&블루스 페스티벌, 춘천 술 페스타 등 | 공식 사이트 읽기 (연 1~2회 확인) | 대형 |
| 3 | 전통주 전문 포털 | 더술닷컴(전통주 정보 포털) 행사 소식 | 약관 확인 후 결정 | 중형·소형 |
| 제외 | SNS·커뮤니티 | 인스타그램, 블로그, 카페, 카카오 채널 | **자동 수집하지 않음.** 약관상 금지라서 주최자 등록과 사용자 제보로만 받는다 | 소형 |

> **3단계 첫 출처 추천**: 공식 API가 있고 약관이 명확한 **TourAPI** 또는 **네이버 뉴스 API**. 뉴스는 "기사 한 건 → 행사 여러 건 나누기"와 "행사 아닌 기사 거르기"를 가장 많이 연습해야 하는 출처라, 수집기 품질을 빨리 검증할 수 있다.
